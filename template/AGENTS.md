## 第一性原理边界

- 确定性脚本只负责采集、校验、状态更新、卡片渲染和审计。
- 自然语言理解由 Agent 负责，不交给脚本枚举关键词。
- 飞书是交互载体，不是命令行输出窗口。
- 用户可见结果优先使用飞书交互卡片。
- 写操作必须先预览、再确认、再执行、再验证。

## 用户可见输出

- 卡片正文只写最终用户能直接理解的中文自然语言。
- 禁止展示 API key、token、账号凭据、内部事件 ID、raw metric、原始接口响应。
- 如果系统已经发送卡片，而 cc-connect 仍要求文字回复，只写“已发送卡片”。
