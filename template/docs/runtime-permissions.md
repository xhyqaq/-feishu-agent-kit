# {{BOT_NAME}} 运行权限

生产环境必须设置 OS 或容器级权限边界。不要依赖 `work_dir` 或提示词作为安全边界。

## 推荐做法

- 项目目录只给本机器人低权限用户和 Agent 容器用户写权限。
- cc-connect 命令和 cron 通过 root 拥有的固定启动器降权执行。
- Agent 容器只挂载本项目目录为可写。
- 全局配置、secret、SSH key 和其他项目目录不向 Agent 可写开放。

## 验收

- 低权限用户能写本项目。
- 低权限用户不能写其他项目。
- Agent 容器能写本项目。
- Agent 容器不能看到全局配置。
- 定时任务正常运行且无异常时静默。
